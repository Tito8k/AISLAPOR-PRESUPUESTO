# Clasificador Zig-Zag · EPS (Aislapor)

Sitio estático del proyecto (Universidad de los Andes · Ingeniería Mecánica · Proyecto 3 · Grupo 9).

Abrir `index.html`. Cada página es un HTML autocontenido; el modelo 3D carga three.js desde unpkg (requiere internet).

## Páginas
- `index.html` — inicio con las 4 versiones
- `zigzag-1.html`, `simulacion.html`, `planos.html` — 1.0 Caja MDF + acrílico
- `zigzag.html#2` / `#3` — modelo 3D del 2.0 (Prototipo 23) y 3.0 (caja superior de aluminio)
- `simulacion-23.html#2` / `#3` — simulación física 2.0 / 3.0
- `planos-piezas.html#1` / `#2` / `#3` — vistas, explosionados, piezas y planchas de corte (MDF 5,5 mm)
- `original.html`, `simulacion-original.html` — 4 · equipo de fábrica
- `equipos.html` — otras simulaciones
- `presupuesto.html` — presupuestos y lucro cesante
- `validacion.html` — ensayo real del 1.0 y resultados esperados

## STL (mm, Z arriba, origen común)
- `stl/Prototipo23_ensamble/` — 2.0 completo + piezas
- `stl/Zigzag3_ensamble/` — 3.0 completo + piezas
- `stl/deflector_superior.stl`
